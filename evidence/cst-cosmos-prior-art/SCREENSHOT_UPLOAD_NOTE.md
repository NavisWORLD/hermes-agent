# Screenshot exhibit preservation

The documentary exhibit index in this archive corresponds to ten original screenshots supplied by Cory Davis on 2026-08-13. The repository's connected text-file writer cannot serialize binary PNG/JPEG attachments directly. The original binary files are preserved separately in the accompanying evidence bundle and should be copied into `screenshots/` without modification, then verified against SHA-256 hashes generated from the originals.

This note is procedural only and makes no substantive allegation.
